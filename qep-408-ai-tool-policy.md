# Policy

In all repositories and systems within the QGIS project, construed broadly, LLM-generated text 
(e.g. pull requests/issues titles, descriptions and comments), bits created by AI agents, 
or similar non-human-generated content is prohibited.

This does not include the source code contributions that may be subject to different policies depending on 
the individual repository (see for example the qgis/QGIS repository in the remaining of this document).

The social contract is that QGIS is a collaboration among humans. Labeled LLM text is contrary to that social 
contract, and unlabeled LLM text is a misrepresentation.

No LLM, AI or agent assisted code contributions are allowed in the https://github.com/qgis/QGIS repository.
If we subsequently discover that you have used an AI, LLM, or any agent-based workflow for your
contribution, you will be subject to code reversion and contributor rights sanctioning.
