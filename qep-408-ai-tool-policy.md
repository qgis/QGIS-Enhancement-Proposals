# Policy

No LLM, AI or agent assisted code contributions are allowed in the https://github.com/qgis/qgis repository.
If we subsequently discover that you have used an AI, LLM, or any agent-based workflow for your
contribution, you will be subject to code reversion and contributor rights sanctioning.


## Exceptions to the default policy

**Trusted contributors** in this section are defined as contributors with at least 100 merged pull requests in qgis/QGIS repository.

**Only trusted contributors** can use AI tools to craft their contributions, but with the following requirements:
- they must be transparent and label contributions that contain any amounts of tool-generated content
- they must read and review all generated code before opening a pull request and they must be able to answer questions about their work
- they must state that they own the code (the contributor is always the author and is fully accountable for their contributions)
- they must provide full transcript of their chat/agent session linked from the pull request
